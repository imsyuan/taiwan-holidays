訂閱台灣假日行事曆（含補班日）

把台灣國定假日與補班日一次加進你的 Google 日曆、Apple 行事曆或 Outlook：訂閱一次，之後新年度公布、政府臨時調整假期，行事曆都會自己更新。免費、免登入，涵蓋 2017–2027 年。

一鍵訂閱

訂閱台灣假日行事曆

點上方按鈕，iPhone、iPad、Mac 與多數桌面行事曆 App 會自動打開並詢問是否訂閱。Google 日曆與 Outlook 網頁版不接受這種網址，請照下面的步驟手動貼上。

訂閱網址（HTTPS，手動貼上時用這個）：

https://tw-holidays.gooliya.com/calendar/tw-holidays.ics

只想匯入一次、不要自動更新？可以下載 .ics 檔，但匯入的內容之後不會跟著更新，通常不建議。

Google 日曆

  1. 用電腦打開 Google 日曆（calendar.google.com）。手機 App 不能新增訂閱，但在電腦加好後，登入同一個帳號的手機會一併顯示。
  2. 在左側「其他日曆」旁按「＋」，選「從網址新增」。
  3. 貼上 https://tw-holidays.gooliya.com/calendar/tw-holidays.ics，按「新增日曆」。

Google 重新抓訂閱日曆的時間由 Google 決定，可能延遲半天到一天以上，無法手動要求立即更新。

Apple 行事曆（iPhone、iPad、Mac）

  1. 最快的方式：在 iPhone、iPad 或 Mac 上點本頁上方的「訂閱台灣假日行事曆」按鈕，再按系統跳出的「訂閱」。
  2. 手動加入（iPhone、iPad）：打開齒輪圖示的系統 App，進入「行事曆」→「帳號」→「加入帳號」→「其他」→「加入訂閱行事曆」，貼上 https 網址。
  3. 手動加入（Mac）：行事曆 App 的選單列選「檔案」→「新增行事曆訂閱⋯」，貼上 https 網址，更新頻率選「每天」。

Apple 可能顯示不安全提示：訂閱時系統有時會警告來源不安全，原因是 webcal:// 這個網址格式本身沒有標示是否加密，系統無法事先確認。本站檔案實際以 HTTPS 提供，內容只有公開的假日資料，不含任何個人資料。你可以選「訂閱」繼續；想避開提示，就用上面的手動方式貼 https:// 網址。實際跳出的文字依系統版本而異。

Outlook

  1. 用瀏覽器打開 Outlook 網頁版（outlook.live.com 或公司的 Microsoft 365 信箱），切到「行事曆」。
  2. 按「新增行事曆」，選「從網際網路訂閱」。
  3. 貼上 https://tw-holidays.gooliya.com/calendar/tw-holidays.ics，取個名稱（例如「台灣國定假日與補班日」），按「匯入」。

傳統桌面版 Outlook 的操作路徑因版本而異，建議先在網頁版訂閱，桌面版登入同一個帳號後會一併顯示。Outlook 重新抓訂閱的間隔由 Microsoft 決定，可能需要數小時到一天以上。

訂閱內容

  • 國定假日：每個放假日一筆全天事件，含補假、調整放假與落在週末的假日；一般週末不列入。
  • 補班日：每個補班日一筆全天事件，標題為「補班：…」。
  • 事件備註附上本站對應的連假頁或年度頁，可直接點進去看請假攻略。
  • 所有事件都標成「有空」，不會讓你的行程顯示忙碌。
  • 內容由 scripts/generate_ics.py 從 data/ 自動產生，與本站 JSON API 是同一份資料。

常見問題

訂閱後行事曆會自動更新嗎？

會。檔案內建每日更新提示，我們每週檢查一次政府公告；新年度公布或政府臨時調整假期後，訂閱中的行事曆會跟著更新。實際多久重新抓一次，由 Google、Apple、Microsoft 各自決定，可能延遲半天到一天以上。

補班日也會出現在行事曆嗎？

會。每個補班日是一筆全天事件，標題為「補班：…」，一眼就能分辨。政府該年度沒有公告補班時，就不會有補班事件。

訂閱的假日會讓我的行程顯示忙碌嗎？

不會。所有事件都標成「有空」，只是提醒，不會擋住別人排會議的時段；實際顯示方式仍取決於你的行事曆 App。

Apple 行事曆跳出不安全提示該怎麼辦？

訂閱時 iPhone 或 Mac 可能提示來源不安全，原因是 webcal:// 這個網址格式本身沒有標示是否加密。本站檔案實際以 HTTPS 提供、內容只有公開的假日資料。想避開提示，可改用手動加入訂閱行事曆，貼上 https:// 開頭的網址；實際跳出的文字依系統版本而異。

資料從哪裡來、可以拿去用嗎？

來源是行政院人事行政總處的「中華民國政府行政機關辦公日曆表」（政府資料開放平台資料集 14718），依政府資料開放授權條款－第 1 版釋出。本站整理後的資料以 CC BY 4.0 提供，引用請標示出處。目前涵蓋 2017–2027 年，以政府最終公告為準。
