常見問題

The FAQ below is currently in Chinese. Developers: see llms-full.txt for the full English-friendly reference.

2026 年台灣國定假日總共有幾天？

依政府公告資料，2026 年台灣國定假日（不含週六日）共 22 天，涵蓋開國紀念日、農曆春節、和平紀念日、兒童節、清明節、勞動節、端午節、中秋節、教師節、國慶日、台灣光復節、行憲紀念日等。

2026 年最長連假是哪一段？

農曆春節，依現有政府公告資料自 2/14（六）至 2/22（日）共 9 天，是 2026 年最長的連續假期，實際天數以官方最終公告為準。

2026 年有補班日嗎？

截至目前資料，2026 年尚未有公告需要補班的日期；如政府後續調整，本站資料會透過每月自動同步更新。

這份假日資料多久更新一次、來源是哪裡？

資料每月透過 GitHub Actions 自動從中華民國行政院人事行政總處的政府開放資料（data.gov.tw）同步，並提供 JSON API 供程式串接，不是人工維護的靜態清單。

可以用程式或 AI agent 直接查詢、計算工作日嗎？

可以。除了網站與 JSON API，本專案也提供一個 MCP server，讓 AI agent 能直接計算工作日、扣抵補班、規劃最佳請假組合，而不只是查詢單日是否放假。設定方式見上方「給開發者與 AI 的入口」。
